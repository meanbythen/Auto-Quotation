# 理赔报价机器人

当前版本：**v3.17.30**（平级移交改用新标签页打开）

基于 Python、Playwright 和 Tkinter 的理赔报价自动化工具，支持定损同步、零件查价与改价、报价提交、高额案件提交上级、平级移交及工作记录。

## 本次更新

- 平级移交改为在新标签页打开：复用已开的平级移交标签页，否则新开标签页直连；「理赔作业门户」标签不再被跳走。
- 采集意见可安全停止：按钮双态「🧾 采集意见 / ◼ 停止采集」，点停止后等当前报案号采集完成再停，浏览器不关、数据不残缺。
- 我的任务只查询一次：逐案在新标签页打开报价处理 → 采集意见 → 关闭该页 → 下一个；不再每案重开重查。
- 自动点「取消」关闭「友情提示：车险理赔系统最新版本为 32190…是否跳转」弹窗（我的任务与报价处理页都会处理）。
- 意见采集新增「角色 / 姓名」字段（写入原始 JSON，日志摘要带角色），便于区分定损员/核损员/报价员意见。
- 空闲采集：工具栏「🧾 采集意见」按「我的任务 → 三月内/全部」逐页逐案读取报价处理意见并入库，只读不改案件。
- 低碳信息采集：同步定损后读取「低碳信息」页签配件并落库，空列表按普通配件流程；报价流程暂未改变。
- UI 元素缓存：记住成功命中过的选择器，下次优先复用，失效自动回退；`BOT_ELEMENT_CACHE=0` 可关闭。
- 智能意见接入离线模型：规则优先，规则未命中由模型补充；`auto` 模式高置信的「等待资料 / 无需处理」会自动跳过本单并记台账。
- 智能意见支持「确认」模式：中置信度弹窗人工确认，结果落库为训练标签，可导出训练集。
- 扫描报案号时列表为空改为有界轮询等待，不再点击『查询』触发整页重新加载；超时走菜单兜底。
- 新增 P0 智能意见判断：进入报价页后读取「报价处理意见列表」最新一条，给出建议动作并采集语料。
- 判断结果写入审计日志与 Excel 台账备注；P0 只建议不执行，`INTELLIGENCE_MODE=off` 时与旧版完全一致。
- 语料落 SQLite（opinion_corpus / opinion_label / opinion_prediction），支持导出 JSONL 供后续训练。
- 报价任务提交对话框按人员代码分流：已处理过的九级报价案件人员代码自动带入时直接提交，不再填组别代码；首次接收才填组别代码联动带出人员。

## 运行

- Windows：运行 `dist/理赔报价机器人.exe`。
- 源码：安装依赖后执行 `python gui.py`。

## 构建

```powershell
python -m PyInstaller "理赔报价机器人.spec" --clean --noconfirm
```
