# 理赔报价机器人

当前版本：**v3.17.18**（平级移交目标人员选中校验与弹窗内定位）

基于 Python、Playwright 和 Tkinter 的理赔报价自动化工具，支持定损同步、零件查价与改价、报价提交、高额案件提交上级、平级移交及工作记录。

## 本次更新

- 平级移交目标人员不再以「输入框非空」判定成功：必须候选回填含姓名、生成已选标签或候选下拉收起，否则清空重试，两次失败明确中断，绝不提交空目标。
- 目标人员输入框与提交按钮只在「任务提交」弹窗内定位，避免残留在其它标签页的同名控件被误填误点。
- 报价任务提交对话框按人员代码分流：已处理过的九级报价案件选完「九级报价」后人员代码自动带入上次报价员，直接提交任务、不再填组别代码；首次接收才填组别代码联动带出人员。
- 提交成功后轮询识别「系统提示」里的快速链接专栏，点「处理」在当前页完成「报价完成」并提交；无专栏才回退平级移交。

## 运行

- Windows：运行 `dist/理赔报价机器人.exe`。
- 源码：安装依赖后执行 `python gui.py`。

## 构建

```powershell
python -m PyInstaller "理赔报价机器人.spec" --clean --noconfirm
```

## 数据与记录

- 工作记录：`data/ledger/工作记录_YYYYMM.xlsx`
- 运行、审计与错误日志：`data/logs/`
- 本地价格及处理历史：`data/price_cache.db`
